# GPS 定位器 繁體中文版 2.0.0-tw.13（debug 版）

[0xfnzero/gps-locator](https://github.com/0xfnzero/gps-locator)（MIT 授權）的繁體中文 fork。完整操作請看 [使用說明](https://github.com/wahaha232/gps-locator-tw/blob/main/docs/USER_GUIDE.zh-TW.md)。

## 這版變更（相對 2.0.0-tw.12）

- **改由雲端自動建置與發佈**：從這版起，APK 由 GitHub Actions 建置並用固定的 debug 簽章金鑰簽章（和 GPS Tracker 同一套做法），不再依賴特定電腦。功能與 tw.12 完全相同，沒有程式行為變動。
- 簽章憑證與先前所有版本相同，可直接覆蓋安裝。

## 安裝／更新

已安裝 tw.8 以上：打開 App，「設定」→「檢查更新」→「立即檢查」，在系統安裝畫面按「安裝」。手動安裝：下載 `gps-locator-tw-2.0.0-tw.13-debug.apk`（**非 Play 商店正式簽章**）。SHA-256 見附檔 `.sha256`。
