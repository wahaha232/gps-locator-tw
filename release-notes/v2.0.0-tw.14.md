# GPS 定位器 繁體中文版 2.0.0-tw.14（debug 版）

[0xfnzero/gps-locator](https://github.com/0xfnzero/gps-locator)（MIT 授權）的繁體中文 fork。完整操作請看 [使用說明](https://github.com/wahaha232/gps-locator-tw/blob/main/docs/USER_GUIDE.zh-TW.md)。

## 這版變更（相對 2.0.0-tw.13）

- **版本號直接顯示**：首頁的「設定」視窗標題現在會寫出版本號（例如「設定 · 2.0.0-tw.14」），不用再進「關於與支援」才看得到。其他功能沒有變動。

## 安裝／更新

已安裝 tw.8 以上：打開 App，「設定」→「檢查更新」→「立即檢查」，在系統安裝畫面按「安裝」。手動安裝：下載 `gps-locator-tw-2.0.0-tw.14-debug.apk`（**非 Play 商店正式簽章**）。SHA-256 見附檔 `.sha256`。
