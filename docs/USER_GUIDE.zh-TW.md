# GPS 定位器（繁體中文版）使用說明

版本：2.0.0-tw.2　適用：Android 8.0 以上
用途：在**自己有權測試的裝置**上做模擬位置與路線模擬（開發、QA、除錯定位功能）。本 App 不會隱藏 Android 的模擬位置旗標，也不會繞過其他 App 的檢查；有些 App 偵測到模擬位置時仍可能拒絕運作。

---

## 1. 安裝與第一次設定

1. 從 GitHub Release 下載 `gps-locator-tw-2.0.0-tw.2-debug.apk`，在手機上點開安裝（要允許安裝未知來源的應用程式）。
   - 這個 APK 是用 Android debug 金鑰簽署，**不是 Play 商店的正式簽章**；若手機上已有別種簽章的同名 App，要先解除安裝。
   - 部分小米／紅米手機要先到「開發人員選項」開啟「透過 USB 安裝」，才能用 adb 安裝；直接點 APK 安裝不受影響。
2. 打開手機的「開發人員選項」。沒有的話：設定 →「關於手機」→ 連續點「版本號碼」七次。
3. 開發人員選項 →「選取模擬位置應用程式」→ 選 **GPS 定位器**。
   - 在 App 裡也可以點首頁的橘色提示橫幅「選取模擬位置應用程式」，或「設定」→「模擬位置設定」，會帶你過去。
4. 回到 App，第一次開始模擬時依提示允許定位與通知權限。

> 同一時間只能有一個 App 當「模擬位置應用程式」。要換成別的模擬位置 App，就在同一個畫面改選。

## 2. 首頁：單點模擬

| 位置 | 功能 |
|---|---|
| 頂列標題區 | 點一下打開「地區搜尋」（選國家／城市／地區，搜尋地點） |
| 頂列四個圖示 | 地區搜尋、路線模擬、收藏位置、設定 |
| 地圖中央的圖釘 | 目前選到的位置；拖曳地圖就會改變 |
| 地圖右側 ＋／－ | 放大、縮小地圖（也可以兩指縮放） |
| 地圖右下的定位鈕 | 回到手機目前的真實位置 |
| 緯度／經度欄位 | 看目前座標，也可以直接輸入（緯度 -90～90、經度 -180～180） |
| 狀態膠囊 | 顯示「未啟動／正在模擬」與精度；右邊的星號＝收藏目前座標 |
| 開始模擬 | 把手機的位置改成圖釘所在的座標 |
| 停止 | 結束模擬，恢復真實定位 |

小提示：
- 模擬中拖曳地圖到新位置，再按「更新位置」就會跳過去。
- 「設定」→「搖桿微調」可以用方向鍵一小步一小步移動位置（可選移動步長）。
- 第一次啟動且沒有任何已儲存位置時，地圖起點是**台北**；之後會記得上次的位置。

### 收藏與紀錄
- 星號：收藏目前座標（可命名、分組），用「收藏位置」圖示管理；點收藏項目可直接用該位置開始模擬。
- 「設定」→「位置紀錄」：曾經模擬過的位置，可再次使用、存成收藏或刪除。

## 3. 路線模擬

首頁頂列的路線圖示（或「設定」→「路線模擬」）進入**路線編輯器**。

### 3.1 建立路線
1. 把地圖移到想要的位置，按「新增地圖中心點」加入一個途經點；重複加入多個點。加錯了按「復原途經點」。
2. 輸入路線名稱。第一次可以按「範例」載入一條示範路線來熟悉操作。
3. 設定速度（見 3.3）、是否「循環路線」。
4. 按「儲存並開始」。

### 3.2 匯入 GPX／KML
有三種方式：
- **已儲存路線**（頂列右邊的路線圖示）→ 視窗裡的「匯入 GPX/KML」→ 從系統的檔案選擇畫面選檔（現在不限制檔案類型，所有檔案都選得到）。
- **掃描手機中的 GPX**（頂列的搜尋圖示）：掃描整支手機，列出所有 `.gpx`，可依檔名或資料夾即時搜尋，最近修改的排最前面，點一下就匯入。
  - 需要「所有檔案存取權」：按畫面上的按鈕，到系統設定打開，再回到 App 會自動掃描。
  - 不想授權的話，按「選擇資料夾掃描」，只掃你選的資料夾（不需要額外權限）。
  - 檔案只在本機讀取，**不會上傳**。
- 匯入後路線會直接載入編輯器，你可以調整速度再開始。

匯入大小與簡化：
- GPX：檔案上限 **300 MB**，十萬點以上也能匯入。匯入時邊讀邊簡化，**最後最多保留 3000 個點**（均勻抽稀，保留起點與終點，也保留每個點的原始時間）。匯入在背景進行，有進度視窗，可以取消。
- KML：檔案上限 10 MB，同樣簡化為最多 3000 點。
- GPX 有多條 `<trk>` 時只用第一條。
- 匯入失敗時，訊息會寫出原因（例如「Not a GPX document」）。

### 3.3 速度與播放方式
- **速度預設值**：🚶 走路 5、🏃 跑步 10、🚲 騎車 18、🚗 開車 40（公里/小時）。按下後可再用滑桿微調（1～160）。目前速度剛好等於某個預設值時，那顆按鈕會高亮。
- **依 GPX 時間播放**（匯入的 GPX 每個點都有時間才會出現這個開關）：保留原本走走停停的快慢，速度由時間戳記決定；開著時速度滑桿與預設按鈕會變灰。關掉就回到固定速度。
  - 只要原檔有任何一個點沒有時間，就不能依時間播放。
- **速度自然起伏**（固定速度時可選）：起步時從慢慢加速到全速，之後在 ±20% 內緩慢變化；每次播放的變化都一樣。
- **GPS 中斷**（編輯器左下的按鈕）：模擬進隧道、搭捷運。新增「從第 N 秒起、持續 M 秒」：這段時間**不送出任何位置**，但模擬的人照常前進，所以中斷結束時位置會跳到前進後的地方。可以設多段，點清單裡的項目可刪除。時間以模擬時間計算，快轉時也對得上。

### 3.4 播放中控制
開始路線後，首頁控制面板會出現：
- **進度列**：已播放時間、總時間、剩餘時間、目前速度（循環路線沒有總時間）。
- **暫停／繼續**：暫停時人停在原地，仍持續送出同一個位置（速度 0）。
- **倍速**：點一下輪流切換 ×1、×2、×4、×8。
- 通知列也有暫停／繼續與停止按鈕。

### 3.5 管理與匯出
「已儲存路線」→ 點一條路線：開始、載入編輯、匯出 GPX、匯出 KML、刪除。
注意：匯出的 GPX **不含時間戳記**，匯出後再匯入會變成固定速度。

## 4. 設定頁

首頁右上角的設定圖示，項目有：路線模擬、位置紀錄、搖桿微調、雲端同步、團隊範本、語言、企業授權、隱私與資料、關於與支援、**模擬位置設定**、**無障礙設定**、開發人員選項。

- **語言**：跟隨系統、简体中文、繁體中文、English、日本語、Español。
- **模擬位置設定**：還沒設好會帶你完成設定；已設好會告訴你目前狀態，並可前往開發人員選項更換。
- **無障礙設定**：直接開啟系統的無障礙設定頁。
- **隱私與資料**：所選座標、收藏、路線、紀錄都存在本機；可一鍵「清除本機測試資料」。
- **雲端同步／團隊範本／企業授權**：進階功能（加密備份、分享位置與路線範本、ADB 批次控制的授權），一般使用者可以忽略。

外觀：配色跟隨系統的淺色／深色模式。

## 5. 常見問題

**GPX 在選擇畫面是灰色、點不了？**
新版已不限制檔案類型；若仍選不到，改用「掃描手機中的 GPX」。

**掃描不到檔案／一直要求權限？**
掃描整支手機需要「所有檔案存取權」。授權後回到 App 會自動掃描；或改用「選擇資料夾掃描」。Android/data 與 Android/obb 內的檔案系統不允許一般 App 讀取，掃不到是正常的。

**按「開始模擬」沒反應或顯示失敗？**
先確認「選取模擬位置應用程式」選的是 GPS 定位器，並允許定位與通知權限；檢查有沒有別的 App 搶走模擬位置設定。

**其他 App 還是顯示真實位置？**
有些 App 會偵測模擬位置，或使用 Wi-Fi／基地台定位，本 App 無法控制；請先在 Google 地圖確認位置有跳過去。

**第一次打開為什麼是台北？**
沒有已儲存的位置時的預設起點；之後會記住上次位置。

**匯入很久？**
幾十 MB 的 GPX 要邊讀邊簡化，手機上可能要幾十秒；進度視窗有「取消」。

## 6. 目前已知限制

- 匯出的 GPX 不含時間戳記。
- 單一路線最多 3000 個點（匯入時自動簡化）。
- 以下項目目前**只有單元測試與編譯驗證，尚未在實機完整驗證**：實際開始模擬後的暫停／倍速／進度列、授予「所有檔案存取權」後的掃描、超大 GPX 的匯入速度、淺色模式外觀、修正後的 GPX 檔案選擇畫面。
