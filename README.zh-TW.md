# GPS 定位器 繁體中文版

這是 [0xfnzero/gps-locator](https://github.com/0xfnzero/gps-locator)（MIT 授權）的 fork，原作者版權與授權聲明保留在 [LICENSE](LICENSE)。
用途與上游相同：給開發與 QA 在**自己有權測試的裝置**上做模擬位置與路線模擬；不會隱藏 Android 的模擬位置旗標，也不會繞過其他 App 的檢查。

## 這個 fork 改了什麼

- **繁體中文（zh-TW）**：完整介面翻譯（台灣用語），語言選單新增「繁體中文」。
- **介面重新設計**：青綠藍加珊瑚色的新配色、膠囊形按鈕與浮動頂列、圓角底部面板與把手、狀態膠囊；支援深色模式；路線編輯器的速度預設值有選取狀態。
- **速度預設值**：走路 5、跑步 10、騎車 18、開車 40 公里/小時，仍可用滑桿微調。
- **GPX 依時間戳記播放**：匯入帶時間的 GPX 時保留原本走走停停的快慢（可切回等速）。
- **模擬 GPS 中斷**：播放到第 N 秒起連續 M 秒不送出位置，人照常前進，恢復後位置會跳到前進後的地方（例如進隧道、搭捷運）。
- **播放中控制**：暫停／繼續、倍速（×1、×2、×4、×8）、進度列（已播放、剩餘、目前速度）；通知列也有暫停／繼續。
- **速度自然起伏**：等速模式下可選，起步加速並在 ±20% 內緩慢變化（固定、可重現）。
- **設定頁**新增「模擬位置設定」與「無障礙設定」的快速入口。
- **大型 GPX 匯入**：GPX 以串流方式邊讀邊簡化（檔案上限 300 MB，十萬點以上也能匯入），最後均勻抽稀為最多 3000 點（保留首尾與每個點的原始時間）；匯入在背景進行，有進度視窗並可取消。KML 也簡化為最多 3000 點（檔案上限 10 MB）。
- **搜尋／掃描手機中的 GPX 檔案**：路線編輯器頂列的搜尋圖示會掃描內部儲存與 SD 卡裡所有 `.gpx`（需要「所有檔案存取權」，Android 10 以下是讀取權限），可依檔名或資料夾即時篩選、最近修改的排最前，點一下就匯入（走同一條大檔串流匯入流程）。沒有授權時也可以改用「選擇資料夾掃描」，只掃描你選的資料夾，不需要額外權限。略過隱藏資料夾、符號連結與 Android/data、Android/obb；檔案只在本機讀取，不會上傳。
- **地圖縮放 ＋／－**按鈕（首頁與路線編輯器）；第一次啟動的預設位置改為台北（上游是北京天安門）；GPX 檔案選擇器不再限制檔案類型（避免被判成 octet-stream 的 .gpx 選不到），匯入失敗時訊息會寫出原因。
- **隨機生成軌跡**：路線編輯器頂列的按鈕，從地圖中央產生 2～500 個點、範圍 50～50000 公尺的隨機漫步或環形迴路，可指定隨機種子重現同一條軌跡。
- **啟動時自動定位到現在位置**，右下角「目前位置」按鈕會取新的定位。
- 完整操作請看 [使用說明](docs/USER_GUIDE.zh-TW.md)。
- **穩定性與安全強化**：匯入檔案與網路回應一律設大小上限（GPX 300 MB（串流）、KML／JSON 路線檔 10 MB、授權檔 1 MB、地點搜尋回應 2 MB、雲端同步回應 70 MB）；地點搜尋快取改為 LRU（上限 200 筆）；ADB 控制入口限制名稱與路線文件長度；新增語系完整性測試（各語系字串鍵與格式佔位符必須與預設一致）。

## 編譯

需要 JDK 17 與 Android SDK 35：

```bash
./gradlew assembleDebug testDebugUnitTest
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`。安裝後，到手機的開發人員選項把「選取模擬位置應用程式」設成 GPS 定位器。

## 已知限制

- 匯出的 GPX 不含時間戳記（匯出後再匯入會變成等速）。
- 深色模式與淺色模式的外觀只在深色模式的實機上看過；播放控制（暫停、倍速、進度列）只有單元測試與編譯驗證。
