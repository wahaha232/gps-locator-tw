# GPS 定位器 繁體中文版

這是 [0xfnzero/gps-locator](https://github.com/0xfnzero/gps-locator)（MIT 授權）的 fork，原作者版權與授權聲明保留在 [LICENSE](LICENSE)。
用途與上游相同：給開發與 QA 在**自己有權測試的裝置**上做模擬位置與路線模擬；不會隱藏 Android 的模擬位置旗標，也不會繞過其他 App 的檢查。

## 這個 fork 改了什麼

- **繁體中文（zh-TW）**：完整介面翻譯（台灣用語），語言選單新增「繁體中文」。
- **介面重新設計**：青綠藍加珊瑚色的新配色、膠囊形按鈕與浮動頂列、圓角底部面板與把手、狀態膠囊；支援深色模式；路線編輯器的速度預設值有選取狀態。
- **速度預設值**：走路 5、跑步 10、騎車 18、開車 40 公里/小時，仍可用滑桿微調。
- **GPX 依時間戳記播放**：匯入帶時間的 GPX 時保留原本走走停停的快慢（可切回等速）。
- **模擬 GPS 中斷**：播放到第 N 秒起連續 M 秒不送出位置，人照常前進，恢復後位置會跳到前進後的地方（例如進隧道、搭捷運）。
- **播放中控制**：暫停／繼續、倍速（×1、×2、×4、×8）、進度列（已播放、剩餘、目前速度）；通知列也有暫停／繼續。
- **速度自然起伏**：等速模式下可選，起步加速並在 ±20% 內緩慢變化（固定、可重現）。
- **設定頁**新增「模擬位置設定」與「無障礙設定」的快速入口。
- 匯入超過 3000 點的 GPX 會均勻抽稀（保留首尾與原始時間）。

## 編譯

需要 JDK 17 與 Android SDK 35：

```bash
./gradlew assembleDebug testDebugUnitTest
```

APK 在 `app/build/outputs/apk/debug/app-debug.apk`。安裝後，到手機的開發人員選項把「選取模擬位置應用程式」設成 GPS 定位器。

## 已知限制

- 匯出的 GPX 不含時間戳記（匯出後再匯入會變成等速）。
- 深色模式與淺色模式的外觀只在深色模式的實機上看過；播放控制（暫停、倍速、進度列）只有單元測試與編譯驗證。
